# 진행 기록 — 2026-10-01-luma-app.md

- 사용자 지시: 앱 제작을 진행하고 배포는 추후 처리.
- 구현 방식: 이 세션에서 직접 구현. 기존 저장소는 최초 커밋과 작성자 정보가 없는 빈 폴더여서 별도 체크아웃은 만들지 않음.
- Task 1: 완료. 재생 순서·검색·중복·저장 복구 9개 테스트 통과.
- Task 2: 완료. 실제 WAV 메타데이터·하위 폴더 검색·M3U·범위 요청을 포함해 12개 테스트 통과.
- Task 3: 구현 완료, 타입 검사 및 제품 빌드 통과. 화면과 기능을 Electron 통합 테스트로 확인 중.
- 발견 및 수정: EQ 스위치 장식이 체크박스 포인터 이벤트를 가로막아 장식의 포인터 이벤트를 비활성화. 타이머 버튼은 분 단위를 포함한 접근성 이름 부여.
- 최종 검토: 별도 읽기 전용 리뷰 완료. 빠른 곡 교체의 오래된 메타데이터 콜백, 종료 직전 저장, 스캔 항목 실패의 전체 중단을 재현 테스트로 수정. 대기열 후 기존 진행 위치를 유지하도록 보완.
- 회귀 검증: 16개 단위 테스트 및 타입 검사 통과.
- Task 4: 완료. Windows 실행 파일 패키징과 실제 패키지의 파일 가져오기·재생·탐색·목록·EQ·미니 플레이어·타이머 설정·자동 다음 곡·검색·재실행 유지·즉시 종료 위치 저장 통합 검증 통과. 화면을 1320×880 및 960×650에서 확인.
- macOS 로컬 빌드 시도: electron-builder가 macOS 빌드는 macOS 환경에서만 지원한다고 거부. macOS 소스/아이콘/패키징 설정은 준비되어 있으며 설치 파일 생성과 실기기 확인은 macOS 환경에서 남아 있음.
- GitHub 배포는 사용자 지시에 따라 추후 처리. 현재 소스와 Windows 실행 파일은 작업 폴더에 보존.


## 2026-11-07 — MusicBoard 0.2.1 배포와 기존 업데이트 복구

- 앱 화면·미니 플레이어·창 제목·macOS 앱 번들·배포 제목을 MusicBoard로 통일. 기존 설치 경로, 데이터 식별자와 호환 설치 파일명은 유지.
- 0.1.10은 SONO의 정식 배포 URL을 엄격하게 검사하므로 저장소 개명 후 리디렉션 응답을 거부함. 명시적인 승인에 따라 SONO 주소를 임시 복원하고 공식 0.2.1의 파일 9개를 검증 후 복제함.
- 검증 브랜치: https://github.com/contentriumkorea/MusicBoard/actions/runs/42352305278 — 모든 작업 성공. macOS의 실제 배포 0.1.10 앱에서 한 번의 업데이트 클릭으로 0.2.1 교체·재실행·보관함 및 설정 보존 확인. Windows의 기존 0.1.11 설치를 같은 위치에서 0.2.1로 교체하는 시험도 성공.
- 정식 배포: https://github.com/contentriumkorea/MusicBoard/actions/runs/42352690609 — 모든 빌드·시험·게시 작업 성공. 각 플랫폼 프런트엔드 테스트 96개, Rust 서비스 테스트 21개 및 실제 네이티브 화면·재생·편집·데이터 보존 검증 수행.
- 기존 주소 복제: https://github.com/contentriumkorea/SONO/actions/runs/42353045069 — 수동 실행 1회 성공, 공식 파일과 크기·SHA-256 일치. 반복 예약 실행은 사용하지 않음. 작업 표시 이름은 MusicBoard.
- 비인증 공개 검증: 공식 설치 파일 9개를 실제 다운로드하여 크기·SHA-256 검증, 업데이트 매니페스트의 SHA-512 검증, Mac ZIP의 MusicBoard.app 이름·0.2.1 버전·네이티브 실행 파일 확인. SONO의 latest 응답과 9개 다운로드 HTTP 200, 실제 Mac ZIP 체크섬도 확인.
- 새 버전은 공식 MusicBoard 주소에서 업데이트를 확인함. 실제 기존 사용자 앱의 업데이트 적용 확인 전까지 SONO 공개 주소를 유지해야 함. 기존 0.1.10/0.1.11 배포는 마이그레이션 회귀 시험의 고정 다운로드 의존성이 있어 공개 상태를 유지함.
- 남은 확인: 실제 사용 중인 Mac에서 업데이트 버튼을 통한 0.2.1 적용. CI의 격리된 Mac/Windows 검증과 사용자 기기의 설치 완료는 구분함.
