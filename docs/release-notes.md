PulseDeck 0.1.11 — 새 이름과 업데이트 주소 이전

- 앱 안의 이름을 PulseDeck으로 변경
- 업데이트 확인·다운로드 주소를 공식 MusicBoard 저장소로 이전
- 기존 SONO 주소로 이 버전을 받은 뒤에는 PulseDeck에서 다음 업데이트 확인
- 음악 목록·재생목록·이름·설정·파형·음원 길이 설정 유지

기존 앱에서 ‘업데이트 → 지금 업데이트’로 적용해주세요.
이 버전으로 업데이트한 뒤에는 기존 SONO 호환 저장소의 이름을 정리할 수 있습니다.
기존 설치 경로·내부 실행 파일명과 업데이트 자산 이름은 호환성을 위해 유지합니다.
Mac은 ad-hoc 서명을 사용하는 시험 배포이며 Developer ID 서명·공증은 아직 구성하지 않았습니다.
