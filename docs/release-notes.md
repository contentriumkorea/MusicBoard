MusicBoard 0.2.0

- 기존 화면과 조작 방식을 유지하면서 앱 실행·음악 파일 처리·저장·파형 분석·업데이트 처리 개선
- 긴 음원과 확장자가 잘못된 음원의 파형 분석 및 기존 정보 복구
- 폴더 간 곡 이동·원하는 위치에 추가·이름 변경·여러 곡 선택 삭제 유지
- 음원 길이 조정·A–B 구간 반복·페이드 초 직접 입력 유지
- 업데이트 직전 설정을 저장하지 못하면 설치를 중단하고 재시도 가능
- 기존 보관함·재생목록·표시 이름·좋아요·재생 및 음량 설정 유지

기존 설치 앱에서 ‘업데이트 → 지금 업데이트’로 적용합니다.
설치 경로·내부 실행 파일명·MusicBoard/SONO 업데이트 파일명은 호환성을 위해 유지합니다.
Windows에 WebView2 Runtime이 없으면 설치기가 Microsoft 공식 런타임을 설치하므로 이때 인터넷 연결이 필요합니다.
Mac은 기존과 같이 ad-hoc 서명을 사용하며 Developer ID 서명·공증은 아직 구성하지 않았습니다.
